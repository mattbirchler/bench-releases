Support

Workbench is a free Mac app for running Claude Code, with an iPhone app that connects to it.

Getting started

  1. Install Claude Code and sign in.
  2. Download Workbench, open it, and drag Workbench into your Applications folder.
  3. Open Workbench and add a project folder. Workbench > Settings > Setup shows anything that's missing.

Using the iPhone app

  1. Get the Workbench iPhone app from the App Store.
  2. Install Tailscale on your Mac and iPhone, and sign in to the same account.
  3. On the Mac, open Workbench > Settings > Remote Access and turn on the switch at the top (Let my iPhone and other Macs connect).
  4. In the iPhone app, tap Scan Code and scan the code on your Mac.

To look around first, tap Try a Demo on the iPhone app's first screen.

Using another Mac

You can work in a second Mac's projects from the same sidebar.

  1. Install Tailscale on both Macs, and sign in to the same account.
  2. On the Mac you want to reach, open Workbench > Settings > Remote Access, turn on the switch at the top, and click Copy Pairing Link. The link starts with bench://pair.
  3. Send that link to the other Mac (with Universal Clipboard, a note, or a message to yourself).
  4. On the other Mac, click + next to This Mac at the top of the sidebar, paste the link, and click Connect.

The pairing link holds a secret, so keep it to yourself. Click Make a New Code to replace it.

Common problems

"Can't find the Mac." Check that Tailscale is connected on both devices.

"Found the Mac, but Workbench isn't answering." Make sure Workbench is open on the Mac and Let my iPhone connect to Workbench is on in Settings > iPhone.

No notifications on your phone. Turn on notifications in the iPhone app's Settings. Then, on the Mac, right-click each project you want to hear about and choose Send Notifications to iPhone. A bell shows on projects that notify.

Claude tabs say Claude Code isn't installed. Install it, then open a new Claude tab. Settings > Setup shows where Workbench looked.

macOS says Workbench was blocked from modifying other apps. Workbench is a terminal, and macOS counts whatever runs in its tabs as Workbench. When a command or Claude Code updates or deletes an app (such as brew upgrade, or a build that replaces an app it made before), macOS asks about Workbench. Other terminals like Terminal and iTerm get the same prompt. Workbench itself doesn't change other apps. To allow it, turn on Workbench in System Settings > Privacy & Security > App Management. If you leave it off, only that one step fails.

Pull requests don't show up. Install the GitHub CLI and run gh auth login in a terminal.
